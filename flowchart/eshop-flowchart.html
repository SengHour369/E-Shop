1. Services

The browser and Postman talk only to the API gateway on port 8080. Each service keeps its own database.

Browser or PostmanSends every shop request to the gateway
API gateway :8080Checks the token, applies the Redis rate limit, then routes through Eureka

Services behind the gateway

auth-service :8081Accounts, login, verification mail
catalog-service :8082Products, stock, prices, scanner
order-service :8083Cart, checkout, returns
payment-service :8084Payments and Bakong QR
ai-service :8085Decides and calls one tool
notification-service :8086In-app inbox for AI writes
Discovery :8761 tells the gateway where each service is.
gateway-redis :6379 is shared. The gateway counts requests. Each Spring service writes a two-minute startup key. Stock and prices are not cached.
order-service asks catalog for the price, then reserves and confirms stock.
ai-service asks ai-inference :8000 to name one tool. ai-inference calls OpenAI. ai-service then calls catalog or order.
catalog-service calls ai-inference only for a camera image, after no barcode matched.
Kafka carries one notification event. notification-service saves the inbox row and asks auth-service to send mail when the user opted in.
Postgres is separate: auth 5432, catalog 5433, order 5434, payment 5435, gateway 5436, AI 5437, notification 5438. Discovery and ai-inference do not use Redis.
