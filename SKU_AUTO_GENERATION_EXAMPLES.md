e# SKU Auto-Generation - Simple Examples

## Quick Reference

### ❌ DON'T DO THIS (Manual SKU input required)
```json
{
  "sku": "IPH15-BLU-128",
  "price": 999.99,
  "quantity": 40
}
```
User has to manually create SKU codes.

---

### ✅ DO THIS INSTEAD (Auto SKU generation)
```json
{
  "sku": null,
  "price": 999.99,
  "quantity": 40,
  "product_attributes": [
    {"name": "Color", "attributes": [{"value": "Blue"}]},
    {"name": "Storage", "attributes": [{"value": "128GB"}]}
  ]
}
```
**Result**: System auto-generates `ELEC-IPH15-BLU-128`

## What the System Does Internally

```
Input: sku = null
       Product: "iPhone 15"
       Category: "Electronics"
       Attributes: Color="Black", Storage="128GB"

Step 1: Extract Category Code
  Electronics → ELEC

Step 2: Extract Product Code
  iPhone 15 → IPH15 (preserves digits)

Step 3: Extract Attribute Codes
  Color "Black" → BLK (first 3 letters)
  Storage "128GB" → 128 (numeric value)

Step 4: Combine with Delimiter
  ELEC + IPH15 + BLK + 128
  = ELEC-IPH15-BLK-128

Step 5: Check Uniqueness
  Is ELEC-IPH15-BLK-128 in database? NO ✓
  → Save and return

Output: sku = "ELEC-IPH15-BLK-128"
```

## Java Code to Create SKU (Auto-Generated)

```java
// Client code calling the API
ProductSkuRequest skuRequest = ProductSkuRequest.builder()
    .sku(null)  // ← Set to null for auto-generation
    .description("Blue - 128GB")
    .price(new BigDecimal("999.99"))
    .quantity(40L)
    .isDefault(false)
    .lowStockThreshold(10)
    .productAttributes(List.of(
        ProductAttributeRequest.builder()
            .name("Color")
            .attributes(List.of(
                ProductAttributeValueRequest.builder()
                    .value("Blue")
                    .build()
            ))
            .build(),
        ProductAttributeRequest.builder()
            .name("Storage")
            .attributes(List.of(
                ProductAttributeValueRequest.builder()
                    .value("128GB")
                    .build()
            ))
            .build()
    ))
    .build();

// The SKU will be auto-generated by ProductSkuServiceImpl.createSku()
// Result: sku = "ELEC-IPH15-BLU-128"
```

  - Expected: Uses `MANUAL-SKU` (not auto-generated)

✅ Update SKU with sku=null
  - Expected: Preserves existing SKU value (no change)
